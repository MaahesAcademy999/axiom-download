How to install

  1. Tap Download for Android above.
  2. Open the downloaded axiom-v2.8.0.apk.
  3. If asked, allow your browser to install unknown apps — a one-time Android prompt for anything outside the Play Store.
  4. Tap Install, then open Axiom.

Had an earlier test build installed? Uninstall it first — this release is signed with the official key and Android won't update over the old builds.
